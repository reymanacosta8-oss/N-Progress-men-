1. Tus datos

2. Escoge tu plan semanal

Cada comida equivale a un bowl. Selecciona cuántas comidas recibirás cada día. Prepararemos exactamente esa cantidad durante los 7 días.

3. Selecciona tu objetivo

Arroz de coliflor fijo + 1 base adicional + 1 vegetal + 1 proteína.

4. Prepara tus bowls de los 7 días

Las porciones de cada ingrediente son fijas. Arma cada bowl según las comidas diarias de tu plan. Al escoger 1, 2 o 3 comidas por día, aparecerán respectivamente 1, 2 o 3 bowls para preparar en cada día. Cada columna es un bowl independiente. Puedes preparar bowls diferentes para cada día. Extras: base o vegetal +$5; proteína +$10 por plato.

Para enviar el pedido completo y calcular extras, abre el menú desde un enlace web publicado en Safari. Algunas vistas previas de archivos no ejecutan JavaScript.
